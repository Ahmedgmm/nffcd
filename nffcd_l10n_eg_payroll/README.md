# NFFCD Egypt Payroll Rules

Configuration-only localization for `om_hr_payroll`. It supplies a dated Egypt monthly payroll structure, Egyptian social-insurance rates and wage limits, progressive income-tax bands, and overtime inputs.

The 2026 values are deliberately data records so HR/Finance can add a new dated value when a legal rate changes. Before use in production, reconcile three payroll periods with Finance and obtain HR/legal confirmation of the employee regime and any NFFCD-specific rules.
