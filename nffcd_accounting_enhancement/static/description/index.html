تحسينات المحاسبة — NFFCD

إدارة تصنيفات أموال الخزينة، وتوزيع مبالغ القبض والصرف، ومتابعة الأرصدة والتحويلات الداخلية.

تصنيفات مستقلة لكل خزينة

تبدأ كل خزينة بتصنيف «عام»، مع إمكانية إنشاء تصنيفات إضافية من شاشة الدفعة أو إعدادات الخزينة.

قبض وصرف وتوزيع مبالغ

حدد التصنيف أو وزّع المبلغ على عدة تصنيفات. يجب أن يساوي مجموع التوزيع قيمة الدفعة.

تحويلات داخلية مترابطة

حوّل الأموال بين الخزائن والبنوك داخل الشركة وبالعملة نفسها، مع توزيع مستقل لكل طرف وإلغاء مترابط للدفعتين.

أرصدة وتقارير واضحة

تابع المقبوضات والمدفوعات وصافي التحويلات والرصيد المتبقي لكل تصنيف، واطبع كشف حركة أو صدّر البيانات.

ضوابط الرصيد

يمكن منع تجاوز رصيد التصنيف. تُحتسب الأرصدة من القيود المرحلة، وتبقى توزيعاتها محفوظة للمراجعة.
